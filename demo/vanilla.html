Glean Helper — Vanilla HTML demo

This page proves the <glean-helper> Web Component embeds into any host — Vue, React, or plain HTML like this one. Look for the robot button in the bottom-right corner.

Serve this directory and make sure the backend is running on :3001 with ALLOWED_ORIGINS including this page's origin. The widget posts to /api/chat by default; override with api-url if the backend lives elsewhere.
